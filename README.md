## The entry

`main.py` is a stdlib-only Python program that writes one original one-line dad joke to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). No network, fully deterministic — two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```
